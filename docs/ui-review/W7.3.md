# W7.3 Library tab: test plan and results

Code: `tabs/library.rs`, `edit_dialog.rs`, `preview.rs`, `alternatives.rs`, `batch_dialog.rs`; tests in `crates/klm-gui/tests/gui/library.rs` (rows below) and `bugs.rs` (b5, b6).
All checks run headless (egui_kittest, offscreen wgpu, sandboxed `KLM_CONFIG_DIR`); no window is opened on the desktop, the real `%APPDATA%` config is never read, no network call is made (file pickers are stubbed in tests, never opened).
Snapshots: `docs/ui-review/W7.3/before/` (W7.0 branch) and `docs/ui-review/W7.3/after/`.

## Design in short

- The part list is a `ui_kit::table`. `list_parts` and the part checks run on worker threads; the previous rows stay on screen while a reload runs, and the selection is pruned to rows that still exist when the new list arrives.
- Selection is a set of `(category, name)` plus an anchor. Checkbox or ctrl-click toggles, shift-click selects the range between the anchor and the clicked row **in the order shown** (sorted and filtered). "Select all" / "Select none" act on the rows shown. A plain row click makes the row current (detail panel).
- Sim model is `Status::Optional` ("—") when absent. A datasheet or 3D cell that is missing or broken is clickable: datasheet runs the finder, 3D opens the attach dialog.
- Toolbar: Standardise… (plan on a worker, review dialog, Apply), Export selected… (review dialog with an editable ZIP path, export on a worker), Health report… (project only, scan on a worker, findings dialog, copy as CSV). Delete is not shown (W8.1).
- Restyle goes through the same review dialog (dry run with `write = false`, Apply writes).
- Alternatives opens with the selected (else current) part chosen; its "For part" label sits before the dropdown and names it for accessibility.
- Preview thumbnails are 240x180 (were 140x105), the window is wider.
