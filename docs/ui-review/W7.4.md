# W7.4 Search tab: test plan and results

Code: `crates/klm-gui/src/tabs/search.rs`, tests in `crates/klm-gui/tests/gui/search.rs`.
Headless only (egui_kittest, sandboxed config). Results are handed to the tab as `Msg::Done`, so no source or network is touched.
Snapshots: `docs/ui-review/W7.4/before/` (W7.0 branch) and `docs/ui-review/W7.4/after/`.

## Notes

- Thumbnails shrank to 20 px (the kit's fixed 22 px row height); price breaks/MOQ/pack moved into the price tooltip.
- Price header leaks one small string per currency change (`Col` wants `&'static str`).
- Hand-over for W7.3 (`library.rs`): to make "Open in Library" land on the part, add e.g. `library::Msg::Show(mpn)` that sets the filter; then replace the clipboard copy in `Action::OpenLibrary` with `cx.send(Msg::Library(library::Msg::Show(mpn)))`.
- For W7.1: switch `Action::OpenSettings` to `Section::Sources` once it exists.
