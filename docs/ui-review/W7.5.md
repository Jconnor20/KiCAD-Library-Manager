## Core change

`History` has to say which files a snapshot changed, and `klm-core` only recorded the file list inside each snapshot's manifest. Added `snapshot::changes(root, id) -> Result<Vec<Change>>` (about 30 lines, read-only, no format change): it compares snapshot `id` with the next newer snapshot (or the live library for the newest) by file list, then by size and, for text files, content, otherwise modified time (hard links keep it).

## Hand-offs and follow-ups

- **W7.4 (Search):** BOM's "Search" can't set Search's box (`SearchTab::query` is private and `search.rs` isn't mine), so it copies the MPN to the clipboard, logs it and switches tab. To make it direct, add `search::Msg::Query(String)` that sets `query` and runs the search; BOM then replaces the `copy_text` + `cx.tab = Tab::Search` lines in `bom.rs` with `cx.send(AppMsg::Search(search::Msg::Query(mpn)))` plus the tab switch.
- **W7.1 (Settings):** every link uses `Section::General` (Import: Watch folders…, History: Retention settings…, BOM: Set in Settings…). Switch them to the specific variants once they exist.
- **Core:** `snapshot::changes` is new (read-only, no format change).
- **Not done:** BOM's swap isn't saved to the schematic or the alternatives store; a snapshot's "what changed" ignores KiCad's two table files, which the manifest lists only by name.
