## Notes for W7.1-W7.5

- Fonts: Segoe UI Symbol and Segoe UI Emoji are read from `C:\Windows\Fonts` at start-up (also Apple Symbols / DejaVu Sans if present), not bundled, so there is no licence to carry. Without them (non-Windows without DejaVu) those glyphs fall back to boxes; `k1`/`k1b` fail on such a machine.
- Not done here, by design: no tab was restyled. Library's `check_cell`, Search's pin/star buttons and the tabs' own tables adopt the kit in W7.1-W7.5.
- A legacy `cx.log.push(String)` guesses its level from the words "could not", "failed", "can't", "cannot", "nothing was changed", "not found". New code should use `cx.log(Level, …)`.
