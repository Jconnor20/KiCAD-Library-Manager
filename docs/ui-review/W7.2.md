# W7.2 App shell: test plan and results

Code: `crates/klm-gui/src/main.rs` (+ eframe `persistence` feature in `Cargo.toml`), tests in `crates/klm-gui/tests/gui/shell.rs`, `bugs.rs` (b2 tests lose `should_panic`).
All checks run headless (egui_kittest, offscreen wgpu, sandboxed `KLM_CONFIG_DIR`); no window is opened and the real `%APPDATA%` config is never read.
Snapshots: `docs/ui-review/W7.2/before/` (W7.0 branch code) and `docs/ui-review/W7.2/after/`.

## Notes

- Every checklist **Open** button calls `cx.open_settings(Section::General)` (the only variant); once W7.1 adds Libraries / KiCad / Sources / Watch folders, change the `Section` in `App::checklist` per step.
- The checklist shows whenever a step is open (sources count as enabled by default, so a fresh install lacks only library and watch folder), not only on first run; Hide lasts for the session.
- Only Library, History and Clean up dialogs are gated to their tab; Import's and Settings' modals still show everywhere.
- `window.ron` is the only new file; it holds eframe's window geometry.
