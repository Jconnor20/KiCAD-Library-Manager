# W8.1 Delete a part

**Built:** `core/library/remove.rs` (`plan_remove`, `remove_part`), `Store::forget_part`, `klm-cli remove <part> [--category c] [--project dir] [--yes]` (dry run unless `--yes`), and a **Delete…** button in the Library toolbar with a review dialog (ticked parts, or the clicked row).

Rules: the symbol always goes; the footprint, 3D model, datasheet and sim model go only when no other symbol (any category) or footprint references them. A snapshot is taken first. Anything unreadable or unresolvable (unparseable footprint or symbol library, a `..` path) refuses the whole delete. The part is also dropped from KLM's database, and its alternatives and tags when no other part has that MPN.
