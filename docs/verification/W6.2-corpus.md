# W6.2 Real-file import corpus: verification

Run: `cargo test -p klm-core --test corpus_e2e` (about 90 s; needs `testdata/`, see `docs/testdata-manifest.md`, and `kicad-cli`; skips what is missing).
Every case imports through the app's own calls (`read_zip`, `extract_foreign`, `foreign::scan`, `batch::plan/apply`, `attach_zip`) into temp libraries, never the real config, then runs `kicad-cli sym|fp export svg`. SVGs are left in `target/corpus-renders/<ID>/`. A manual probe showed kicad-cli 9.0.0 and 10.0.7 convert the same files alike.
