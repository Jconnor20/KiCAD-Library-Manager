# W6.1 Live API contract check

Each source was called live once (plus a category call where the code uses one). Raw replies are in `crates/klm-core/tests/fixtures/live/` with secrets and Aliyun signed-URL tokens replaced by `REDACTED`; the recorder refuses to write a file that still contains a stored key, and the fixtures were grepped for `access_token`, `bearer`, `client_secret`, `apiKey=`. Live tests: `cargo test -p klm-core --test live_api -- --ignored live` (all `#[ignore]`, read keys from Credential Manager, write nothing outside the fixtures folder). Everyday tests replay the fixtures inside `src/sources/*`.
