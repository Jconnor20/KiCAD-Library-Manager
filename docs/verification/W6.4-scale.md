## Notes

- **Bug found and fixed (R2):** a snapshot restore made while KiCad is open queues `TableOp::Restore(old text)`; applying it wrote the old text over the whole table. Now outside entries (not in the restore text, not KLM-managed) are spliced back in. Still overwritten: an outside change to an entry the restore text also lists.
- **Simulated KiCad-open path:** under a sandbox `kicad_running()` is always false, so `defer_table_op` never queues. The R1/R2 tests write the queue files in the format those functions write.
- **Fixture:** the scale library is written straight to disk because `add_part` runs `kicad-cli` per part.
- **One unexplained failure:** the first `scale_e2e` run after an edit reported `1 passed; 1 failed`. Four later runs were all green. I did not capture the failing output, so I cannot say which test failed or why. Worth a rerun if it recurs.
